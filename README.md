# 🌦️ Weather Prediction Model
This project uses **Linear Regression** to predict the daily maximum temperature based on historical data.

## How to Run
1. Install dependencies: `pip install -r requirements.txt`
2. Run the model training: `python model.py`
3. Launch the interactive UI: `streamlit run app.py`

## Performance
- **R2 Score:** 0.8548
- **MAE:** 2.33°C
