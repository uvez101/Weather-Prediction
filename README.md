## 🔗 Live Demo
Check out the interactive model here: [View App](https://weather-prediction-egypt.streamlit.app/)

## 🚀 Project Overview
This project uses **XGBoost** to predict the daily maximum temperature based on historical data.

## How to Run
1. Install dependencies: `pip install -r requirements.txt`
2. Run the model training: `python model.py`
3. Launch the interactive UI: `streamlit run app.py`

## Performance
- **MAE:** 1.91°C
